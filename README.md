## Overview

**Hotel Reservation System** is a C# project developed to represent the core operations of a hotel reservation application.

The project is organized as a Visual Studio solution and focuses on structuring an application around hotel reservations. Its domain includes the concepts needed to organize the reservation process, such as rooms, guests, and bookings.

## Project Goals

- Practice application development with C# and .NET.
- Organize hotel reservation operations in a software project.
- Apply object-oriented programming concepts.
- Structure and manage a project using a Visual Studio solution.
